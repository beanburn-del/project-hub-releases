Project Hub

by beanburn · 3D / motion creative studio

Project Hub는 beanburn이 작업용으로 만든 개인 크리에이티브 허브입니다. 프로젝트 · 일정 · 레퍼런스 이미지 · 무드보드 · 컬러 팔레트 · 노트를 한곳에서 관리하며, 사용자의 컴퓨터에서만 실행됩니다.

Project Hub is a personal creative hub built by beanburn for studio work. It organizes projects, schedules, reference images, moodboards, color palettes and notes in one place, and runs only on the user's own computer.

Pinterest integration

With the user's permission, Project Hub reads the user's own Pinterest boards and pins and saves them into the user's local reference library, so references collected on Pinterest can be organized together with other references. If the user turns on two-way sync, edits the user makes in Project Hub (board names, new boards, moving pins, new pins, deleting pins) are applied to the user's own Pinterest account. Project Hub does not access other users' data.
