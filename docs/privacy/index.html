Privacy Policy

Project Hub · beanburn · Effective date: October 15, 2026

This Privacy Policy explains how Project Hub ("the app"), made by beanburn, handles information. Project Hub runs only on the user's own computer (127.0.0.1) and the developer does not operate any server that receives user data.

1. Information we access

  • Pinterest: only after the user signs in and grants access, the app reads the user's own account basics (username, account type) and the user's boards, board sections and pins (images, titles, descriptions and links).
  • If the user turns on two-way sync, the app applies the user's own edits (board names, new boards, moving pins, new pins, deleting pins) to the user's own Pinterest account.
  • The app does not access other Pinterest users' data.

2. How information is stored

Retrieved data and the Pinterest access token are stored only in the Project Hub data folder on the user's computer. They are not sent to the developer or to any third party.

3. How information is used and shared

Information is used only to show and organize the user's own references inside the app. We do not sell, rent or share any information, and we do not use it for advertising or analytics.

4. Retention and deletion

The user can disconnect Pinterest at any time in Settings → References → Pinterest, which deletes the stored access token from the user's computer. Access can also be revoked in Pinterest account settings (Apps). Images already saved to the user's local library stay on the user's computer until the user deletes them.

5. Children

The app is not directed to children under 13.

6. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.

7. Contact

  • 사용자가 허락한 경우에만 본인 Pinterest 계정의 기본 정보(사용자 이름 · 계정 유형)와 보드 · 섹션 · 핀(이미지, 제목, 설명, 링크)을 읽습니다.

  • 설정 → 레퍼런스 → Pinterest에서 언제든 연결을 끊을 수 있고, 이때 저장된 토큰이 지워집니다. Pinterest 계정 설정에서도 접근을 취소할 수 있습니다.
